# Kill_bezzangyi

## 의존성 및 실행 환경

- Node.js 16 이상: 검사기, 테스트, 선택적 Stop 훅 실행에 필요합니다.
- 외부 런타임 패키지 의존성은 없습니다. Node.js 표준 라이브러리를 사용합니다.
- `SKILL.md`를 읽을 수 있는 AI 에이전트에서 사용할 수 있습니다.
- 개별 `CHECK` 명령에 필요한 도구는 실행 환경의 `PATH`에 있어야 합니다.
- Stop 훅은 Claude Code용 선택 기능입니다.
- 테스트: `npm test` (추가 패키지 설치 불필요).
