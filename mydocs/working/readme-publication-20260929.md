# README 및 구조 삽화 반영

사용자가 영어·한국어 README 초안과 수식·연구 근거, 생성한 구조 삽화를 포함해 원격 main에 반영하도록 승인했다.

1. 로컬 변경과 원격 main의 동기화 상태를 확인한다.
2. 삽화를 docs/assets/architecture.png에 저장하고 두 README의 도입부와 시작하기 사이에 연결한다.
3. 상대 링크·수식 구분자·파일 형식을 확인한 뒤 문서 변경을 커밋하고 푸시한다.

삽화는 내장 이미지 생성 도구로 제작한 설명용 이미지다. 스크립트의 배정안과 호스트의 실제 실행 역할을 구분하며, 순차 작업은 한 에이전트가 이어갈 수 있다는 설명을 두 언어로 덧붙였다. 기존 Task 9·10 보고서의 미푸시 기록은 당시 상태를 기록한 것이며, 이번 사용자 승인이 문서 게시 단계에 해당한다.

실행 코드와 기존 A/B/C 실험 데이터는 변경하지 않는다.
