# Task 10 — README 수식·원리·연구 근거 추가

영어·한국어 README에 6개 주제, 각 언어 10개 수식 블록을 추가했다. 병렬 독립성, 실행 후보와 용량, 비순환 그룹 병합, 구조 복잡도 벡터, 작업 보존과 멱등성, 검증 결과 재사용을 설명한다. 각 항목에서 수식의 의미·역할·구현 파일·출처 수준을 연결했다.

## 출처 확인과 적용 수준

- Bernstein (1966), Analysis of Programs for Parallel Processing, DOI 10.1109/PGEC.1966.264565: 병렬 실행의 읽기·쓰기 간섭 조건. 원 논문 DOI 본문은 웹 도구로 열리지 않아 원문 전체를 확인했다고 주장하지 않는다. HPF 공식 명세의 Bernstein 조건 설명과 실제 conflicts 구현을 대조했다. 의존 경로와 자원 ID 검사는 프로젝트 적용 부분이다.
- Kahn (1962), Topological sorting of large networks, DOI 10.1145/368996.369025: ACM 검색 결과의 출판사 서지·초록과 코드의 Kahn traversal을 확인했다. 준비 조건·lease·greedy 선택은 Kahn의 정책으로 귀속하지 않았다.
- Herrmann 외 (2018), Acyclic partitioning of large directed acyclic graphs, RR-9163: 기존 설계에 인용된 자료다. HAL 미리보기가 차단되어 저자 소속 대학의 공개 PDF에서 비순환 그룹 그래프 원리를 확인했다. 해당 다단계 분할 알고리즘을 구현했다고 주장하지 않는다.
- Mokhov, Mitchell, Peyton Jones (2018), Build Systems à la Carte: 저자 공개 PDF의 §4.2.2 verifying traces를 확인했다. 이번 문서화에서 재사용 로직과 연결한 관련 연구다. 과거 구현이 이 논문에서 직접 유래했다고 소급 주장하지 않는다.

복잡도 벡터와 작업 보존·멱등성·논리 턴 규칙은 프로젝트 자체 설계임을 명시했다. 기존 연구 기록의 2025년 재귀 분할 논문은 이번에 본문을 확인하지 못했고, 현재 코드의 직접 알고리즘 출처도 확인하지 못했으므로 README에 권위 근거로 추가하지 않았다.

## 검증

두 문서의 수식 내용과 변수 의미, 코드 파일 연결을 비교했다. 내부 링크 46개, 각 문서 수식 블록 10개와 코드 블록 닫힘, Git diff 공백 검사를 통과했다. 문서 구조 확인 스크립트의 최초 예상 수식 수가 9개여서 실패했고 실제 10개를 확인해 예상값을 수정했다. 수식이나 코드 오류는 아니었다.

문서만 변경했다. 회귀·모델 시험을 반복하지 않았으며, 기존 A/B/C 결과나 런타임 구현은 바꾸지 않았다. Markdown 원문 형식은 확인했으나 GitHub 수식 렌더링은 별도로 확인하지 않았다. 커밋·푸시는 수행하지 않았다.
