# Task 6 — 독립 컨테이너 비교 완료

원본과 파생본을 각각 새 컨테이너에서 실행했다. 실제 과제 32회와 동일 상태 판단 32회, 총 64회를 완료했다. 조건당 각 16회이며 전체 관측 검사·종료 기준에 통과했다. 스킬 구현은 시험 중 변경하지 않았다.

## 결과

|---|---:|---:|---:|---:|---:|

판단 시험의 비캐시 입력은 A 282249, B 176185로 37.6% 감소했다. 전체 과제의 비캐시 입력은 33.7% 증가했다. 전체 입력에는 캐시 입력이 포함되며 중복 합산하지 않는다. 현금 청구액 비교는 하지 않았다.

전체 작업에서 원본은 16회 모두 Solo였다. 파생본은 06-discovery 유형의 두 반복에서 각각 두 자식을 실행했고 나머지는 Solo였다. 그 두 실행의 큰 분업·관리 비용이 전체 증가를 주도했다. 판단 전용에서는 B 16회 모두 schedule 호출을 관측했다. helper 실행 후 상세 결과나 내부 코드를 다시 확인하는 사례도 있었다. 계산 스크립트 하나의 효과와 전체 전략 선택의 효과를 동일시하지 않는다.

## 검증

- 최종 공통 Linux 컨테이너 환경의 회귀: A 188/188, B 268/268.
- frozen 패키지 파일과 실행기·과제·채점기 해시를 대조했다. 실행 중 변경 없음.
- CSV 64행/64개 고유 ID, 층·조건별 16행을 확인하고 PowerShell 합계를 Node 집계와 독립 대조했다.
- 사용량 누락·시간 초과 없음. 부모/자식 세션의 마지막 누적 값을 합산했다.
- 종료 후 Gate unmet/abandon/파싱 오류, 미완료 PLAN 행/dispatch wave, pending 보고/journal, 잔여 lease 파일 모두 관측 0건.
- 실험 컨테이너는 종료되어 남아 있지 않다. Docker 실행 이미지는 재현용으로 보존한다.
- git diff --check 공백 오류 없음. 문서 작성 후 제품 실행 코드를 변경하지 않았다.

## 범위와 남은 검증

작은 Node 과제와 제공된 1~32개 작업 상태에 대한 예비 결과다. 품질 동등성이나 일반적인 토큰 절감률을 입증하지 않는다. 동적 재귀 분할·프로세스 강제 종료·실제 자동 Stop hook 재개는 이 비교에서 측정하지 않았다. Claude 인증 401 때문에 Codex를 사용했으며 hook 모의 검사를 실제 자동 동작으로 대체하지 않았다.

상세 보고서·CSV·JSON은 상위 작업 outputs의 kill-bezzangyi-comparison-results.*에 있다. 실험 manifest·실행 로그·작업 사본·재현 스크립트는 상위 작업 work/skill-benchmark에 보존했다. 측정 방법과 실제 수행 범위의 차이는 task_6_step1.md, task_6_step2.md 및 실험 manifest에 기록했다. 원본 로그에서 조건이나 실패를 사후 삭제하지 않았다.
