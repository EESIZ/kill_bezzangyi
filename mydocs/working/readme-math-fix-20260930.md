# README 수식 표시 오류 수정

사용자가 GitHub README에 표시된 `The following macros are not allowed: operatorname` 오류를 보고했다.

1. 두 README에서 같은 매크로를 찾아 영향 범위를 확인한다.
2. 함수·판정 이름의 표기를 operatorname에서 mathrm으로 바꾼다.
3. 수식 내용과 문서 형식을 비교하고 원격 main에 반영한다.

영어·한국어 문서 각각 9곳, 총 18곳을 변경했다. 이름의 글꼴 표기만 바꿨으며 집합·조건·변수나 실행 코드에는 변경이 없다.

수식 블록 10개씩, 두 언어 수식 일치와 기존 내용 대비 치환만 발생했는지 확인한다. 브라우저 도구는 실행 환경 오류로 연결되지 않았다. GitHub의 과거 공개 수식 렌더링 주소도 unknown action 응답을 반환했다. 따라서 GitHub 화면에서 실제 렌더링 성공까지 확인했다고 주장하지 않는다.

최초 자동 승인 검토는 사용량 한도로 실패했으나 사용자의 계속 진행 요청 후 같은 승인 경로로 재시도해 명령이 실행됐다.
