# Task 5 — unlazy 대비 측정방법 설계

요청 범위는 비교 방법 설계다. 벤치마크 실행, 실행기 구현, 전역 설치, 원격 반영은 포함하지 않는다.

1. 원본·현재 구현·기존 평가 기록을 확인해 비교 대상과 검증되지 않은 주장을 구분한다.
2. 동일 상태의 판단 비교와 실제 과제 전체 비교를 분리하고, 토큰·시간·성공의 계산 경계를 정의한다.
3. 과제 유형, 반복·순서 통제, 외부 정답 검사, 실패·중단·멱등성 검사와 수집 자료를 설계한다.
4. 비용 누락·성공 사례 편향·버전 혼동을 검토하고 설계 문서와 실행 전 준비 목록을 남긴다.

결과: research/comparison-protocol.md. 이 단계에서는 스킬의 행동을 변경하지 않으며 절감률을 산출하지 않는다.
