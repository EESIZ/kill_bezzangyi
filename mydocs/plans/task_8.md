# Task 8 — 최소 검증 구현 및 기존 비교표에 C 추가

사용자가 Task 7 재설계안을 이전과 같은 시험으로 비교하도록 진행을 요청했다. 이를 위해 재설계의 실행 가능한 증거 재사용·단일 공식 검사 경로를 구현하고 동결한 C를 실행한다. A/B 데이터와 과제·채점 기준을 수정하지 않는다.

1. 기존 승인/검사 실행기를 재사용하는 증거 맥락 검사기를 구현한다. 닫힌 입력 선언이 없는 경우 재사용하지 않는다.
2. 스킬의 공식 검사 담당, 통합 검사, 재검증과 문서 읽기 규칙을 연결하고 회귀/실패 검사를 수행한다.
3. 새 비교군 C를 파일 해시로 동결한다. 이전의 과제·프롬프트·채점기·컨테이너/모델 설정을 재사용한다.
4. C 전체 과제 16회와 판단 16회를 새 폴더에서 실행한다. 원본 A/B는 재실행하거나 덮어쓰지 않는다.
5. 외부 기능 검사·잔여 상태·실제 기능 사용과 토큰을 감사하고 A/B/C 비교표를 만든다. 후행 C 실행의 시간대/서비스 변동과 제한된 품질 측정을 명시한다.

새 원본/파생본 실행이나 가격 조회는 요청 범위가 아니다. 전역 스킬·훅 설치는 하지 않는다. 스킬의 기존 승인과 수동 판단은 유지하고, 일부 설계 요소가 구현/호스트 지원 밖이라면 그 범위를 결과에 명시한다.
