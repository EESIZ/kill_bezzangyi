# Task 6 — 독립 가상환경 예비 비교 실행

사용자가 Task 5 측정 설계의 실행과 각 조건의 독립 가상환경 사용을 승인했다.

1. Docker와 모델 인증·사용량 기록을 확인하고 동일 실행 이미지를 고정한다.
2. 원본 A와 현재 B를 해시 manifest로 동결하고 독립 컨테이너·세션·작업 폴더를 준비한다.
3. 공통 과제와 외부 정답 검사를 만들고 계측 점검을 먼저 실행한다.
4. 고정한 순서·예산으로 예비 실험을 수행하고 실패·토큰·시간·스킬 사용 여부를 기록한다.
5. 독립 채점과 자료 검산 후 결과와 측정 한계를 보고한다. 준비 장애로 축소한 측정은 원래 전체 실험과 구분한다.

기존 전역 스킬·설정은 변경하지 않는다. 실험용 Docker 엔진은 요청한 가상환경 실행을 위해 시작한다. 실제 조건별 과제·한도·순서는 모델 비교 실행 전에 별도 manifest로 고정한다. 설치본과 원본을 섞거나 사용량 추정치를 실제 토큰이라고 부르지 않는다.
