# Task 10 — README 수식과 연구 근거

사용자는 README에 사용한 수식, 원리, 역할과 논문 출처를 추가하도록 요청했다. 기존 documentation 스킬의 독자 중심·출처 연결 원칙을 적용한다. 문서 변경만 수행하며 구현과 벤치마크는 바꾸지 않는다.

1. 배정·구조 변경·검산·증거 재사용 코드와 기존 연구 기록을 대조한다.
2. 논문·저자 공개본·공식 명세에서 근거를 확인하고 직접 적용, 개념 참고, 프로젝트 자체 규칙을 구분한다.
3. 영어·한국어 README에 같은 수식과 코드 링크를 추가한다. 복잡도 지표를 비용 예측식으로 오인하지 않게 설명한다.
4. 수식과 구현의 일치, 문서 링크, 형식을 확인하고 출처 확인 기록을 남긴다.
