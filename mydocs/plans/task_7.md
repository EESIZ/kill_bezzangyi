# Task 7 — 검증 절차 최소화 재설계

사용자 요청: 검증 절차를 최소화하는 방향으로 재설계한다. 이번 작업의 승인 범위는 설계와 설계 검산이다. 활성 스킬 절차, Gate 의미, 실행 코드, 전역 설치를 바꾸지 않는다. 기존의 필수 재실행 절차와 충돌하는 변경은 설계 문서에서 명시한다.

1. 현재 검증 경계와 중복 실행 경로를 확인한다.
2. 단일 공식 검증 주체, 실제 통합 지점, 예외 중심 검토와 증거 무효화 규칙을 설계한다.
3. 작은 실행 모델에서 중복 반환·재시작·변경·실패·미해결 작업의 반례를 검산한다.
4. 적용 대상 파일, 이전 방식과의 차이, 품질·비용 평가 기준을 문서화하고 최종 설계 결과를 보고한다.

설계 산출물: `research/minimal-verification-design.md`. 계산량이나 검증 횟수의 모델상 감소를 실측 토큰 절감이나 품질 동등성으로 표현하지 않는다. 구현은 이 설계와 구분한다.
